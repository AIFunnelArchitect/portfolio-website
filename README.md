# Personal Portfolio Website

A simple personal portfolio website built using **HTML and CSS**. The website includes a home page that introduces me and a contact page for getting in touch.

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📄 Pages

* **Home** — Introduction and basic information about me.
* **Contact Me** — Contact information and a way to get in touch.

## 🎯 Purpose

This project was created to practice the fundamentals of **HTML and CSS** and to build my first simple portfolio website.

## 📚 What I Learned

* Creating webpages using HTML5
* Structuring content with HTML
* Styling webpages with CSS
* Creating navigation between multiple pages
* Working with layouts, spacing, fonts, and basic styling

## 🚀 Future Improvements

As I continue learning web development, I plan to improve the design and add more functionality using JavaScript and other technologies.
